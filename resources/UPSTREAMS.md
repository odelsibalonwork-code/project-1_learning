# Upstream creative tools

The starter references these public projects:

- [shadcn/ui](https://github.com/shadcn-ui/ui) — composable React UI components. MIT license.
- [Remotion](https://github.com/remotion-dev/remotion) — video creation with React. Review its current license and usage terms before commercial production.
- [Video Shotcraft](https://github.com/Vincentwei1021/video-shotcraft) — shot recipes and motion-design references. Apache-2.0 license.

This repository does not copy code from those projects. The starter's site design, SVG templates, and Remotion composition are original. The package manager downloads the libraries listed in package.json when you run npm install.

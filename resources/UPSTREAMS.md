# Upstream creative tools

The project uses these libraries and assets as production foundations:

- [Next.js](https://github.com/vercel/next.js) — application framework.
- [Lucide](https://github.com/lucide-icons/lucide) — consistent, tree-shakeable UI icons. ISC license.
- [Motion](https://github.com/motiondivision/motion) — interface animation library. MIT license.
- [Remotion](https://github.com/remotion-dev/remotion) — React-based video composition. Its current license permits individual commercial work and teams up to three people, subject to its terms; larger organizations need the applicable company license. Review the [license terms](https://www.remotion.dev/docs/license/pricing) before production.
- [Fontsource](https://github.com/fontsource/fontsource) — self-hosted web-font packages. This project bundles Space Grotesk Variable and DM Mono under their font licenses.
- [shadcn/ui](https://github.com/shadcn-ui/ui) — optional source-owned React components (MIT); install individual components only when a project needs them.
- [Video Shotcraft](https://github.com/Vincentwei1021/video-shotcraft) — motion-design and shot-planning reference. Review upstream notices before reusing any asset or code.

The website design, SVG templates, and Remotion composition in this repository are original. Font binaries are installed through the lockfile; no third-party image pack is bundled. For commercial image work, use a client-supplied or properly licensed image, keep a record of its source and releases, and avoid implying a real brand or person endorsed a concept. Unsplash's [license](https://unsplash.com/license) allows broad commercial use, but its [release and trademark guidance](https://help.unsplash.com/en/articles/2612329-releases-and-trademarks) explains that copyright permission does not automatically clear every depicted person, property, logo, or artwork.

See [CREATIVE_WORKFLOW.md](./CREATIVE_WORKFLOW.md) for a practical art-direction and delivery checklist.

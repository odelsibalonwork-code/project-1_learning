# Creative work that feels authored

Libraries make production faster; they do not replace the decisions that make a site or campaign feel specific. Use this checklist before turning a template into client work.

## Before designing

1. Write one sentence for the audience, the offer, and the action the work should earn.
2. Collect 6–10 references from the client's category and adjacent culture. Note the actual choices that work: composition, crop, type scale, color, light, pacing, and copy. Do not trace a single reference.
3. Choose one art direction and define its rules: type pairing, spacing rhythm, color roles, image treatment, motion behavior, and what the brand should never look like.
4. Build a small, real content set: actual product/service, original copy, working contact details, and images with documented rights. Mark any concept work as a concept; never invent client results or testimonials.

## Website craft

- Design the page around the offer and the next action. Remove sections that do not help a visitor understand, trust, or act.
- Use real responsive images and deliberate crops. Use `next/image` for image delivery; keep original source files separate from web exports.
- Check narrow screens, keyboard focus, reduced motion, readable contrast, empty states, loading, and error states.
- Add motion to explain hierarchy or give useful feedback. Keep navigation, text, and calls to action usable when motion is disabled.
- Use the installed Lucide icons as a consistent set. Avoid mixing unrelated icon packs.

## Graphics and short-form video

- Start with the channel's actual aspect ratio and safe area; keep critical copy away from interface overlays.
- Make a storyboard before animating. Each shot should add information, emotion, or a visual change that supports the message.
- Use a strong first frame, readable captions, controlled pacing, sound levels, and a clear end card. Do not rely on fast cuts or motion alone to create interest.
- Keep editable source files and export web/social deliverables separately. Record dimensions, frame rate, codec, and version.
- Keep a rights log for every photo, illustration, font, track, voice, and client logo. For people, logos, and recognizable property, check releases and intended use rather than assuming an image-site license clears them.

## Project handoff

- Deliver the source, final exports, a preview, and a short usage note.
- Include what changed for mobile, accessibility, performance, and social safe areas.
- Get written client approval for the final copy, claims, brand assets, and usage scope.
- Put the result in a case study with the brief, your role, the decisions you made, and measurable outcomes only when the client has supplied or approved them.

## Installed production resources

- **Space Grotesk Variable** — expressive display and interface typography, bundled locally from Fontsource.
- **DM Mono** — restrained labels and metadata, bundled locally from Fontsource.
- **Lucide** — a single coherent icon system already in the project.
- **Motion** — purposeful web interface animation already in the project.
- **Remotion** — editable React video compositions already in the project.
